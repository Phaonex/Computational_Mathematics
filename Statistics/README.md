# Computational Mathematics: Statistics (R Programming & Data Analysis)

This folder contains the computational implementation and data analysis for two comprehensive statistics courses, consolidated into a single **R Markdown (.Rmd) notebook**.

* **Course 1:** Meaning from Data: Statistics Made Clear (Professor Michael Starbird)
* **Course 2:** Learning Statistics: Concepts and Applications in R (Professor Talithia Williams)

## Project Progression and Scope:

This single notebook provides an integrated journey, starting with a theoretical foundation and culminating in practical computational statistics:

* **Foundations:** The initial sections focus on the core ideas of statistical thinking, **data interpretation**, and identifying misuse of statistics, following the concepts from the first course.
* **Computational Applications:** The later sections transition to **practical computational methods** in the R environment, covering statistical inference, modeling (e.g., ANOVA), and advanced data visualization, as guided by the second course.

## Topics Covered:

* **Descriptive Statistics:** Measures of central tendency, variability, and graphic displays (e.g., histograms, box plots).
* **Statistical Inference:** Confidence intervals, hypothesis testing (as seen in the Rmd example), and p-values.
* **Modeling:** Simple and multiple linear regression and analysis of variance (ANOVA).
* **Advanced Applications:** Categorical data analysis, time series, and multivariate statistics.

## Technologies Used:

* **R:** All analysis and computational demonstrations are implemented in the R programming language.
* **R Markdown (`.Rmd`):** Used as the format to combine code, output, and narrative explanations into a cohesive notebook.
* **R Packages:** Key packages utilized include:
    * `caracas`: For symbolic mathematics and algebraic manipulation.
    * `sets`: For working with mathematical sets.
    * `tibble` and `dplyr`: For modern data wrangling and manipulation.
    * `ggplot2`: For powerful and aesthetic data visualization.

## How to Navigate This Folder:

The entire project is contained within a single file, **`Statistics_Computational_Notebook.Rmd`**. This file is best viewed as a rendered document (e.g., HTML or PDF), which can be generated using RStudio or the `knitr` package. The notebook is structured with headings to separate the two course contents and individual topics.
