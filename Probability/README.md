# Computational Mathematics: Probabilities (Computational Probability - Julia)

This folder contains my self-study projects and implementations focused on the fundamental concepts of probability as covered in the course "What Are the Chances? Probability Made Clear". All code is implemented exclusively in Julia, emphasizing detailed understanding and practical application of probabilistic models.

## Project Progression:

The project begins by investigating the origins of probability from a mathematical arithmetic and discrete mathematics perspective. It then progresses through core concepts, concluding with an introduction to advanced concepts and the implementation of probabilistic models using `Distributions.jl` for Probability Density Functions (PDF) and `Gen.jl` for Probabilistic Programming.

## Topics Covered:

* **Lecture 1:** `a_visual_introduction_to_probability.jl` - Our Random World
* **Lecture 2:** `randomness_and_the_law_of_large_numbers.jl` - The Nature of Randomness
* **Lecture 3:** `expected_value_and_decision_making.jl` - Expected Value
* **Lecture 4:** `random_walks_and_stochastic_processes.jl` - Random Walks
* **Lecture 5:** `the_normal_distribution_and_its_applications.jl` - The Normal Distribution
* **Lecture 6:** `applications_of_the_normal_distribution.jl` - Applications of the Normal Distribution
* **Lecture 7:** `the_central_limit_theorem.jl` - The Central Limit Theorem
* **Lecture 8:** `discrete_probability_and_counting.jl` - The Poisson Distribution
* **Lecture 9:** `binomial_and_geometric_distributions.jl` - Counting
* **Lecture 10:** `conditional_probability.jl` - The Monty Hall Problem and Bayes's Law
* **Lecture 11:** `bayesian_probability_and_updating_beliefs.jl` - The Two-Boys Problem
* **Lecture 12:** `game_theory_and_decision_making.jl` - Game Theory

## Purpose:

These notebooks and scripts are designed to:
* Deepen my theoretical understanding of core probability concepts.
* Develop practical computational skills for applying probability in mathematical modeling using Julia.
* Illustrate numerical aspects of probability in simulations and analyses.
